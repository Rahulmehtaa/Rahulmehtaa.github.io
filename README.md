# Rahul Mehta — Portfolio

A responsive, accessible static portfolio based on the supplied resume. Includes profile, skills, complete career timeline, education, email and LinkedIn links. No dependencies or build step required.

## GitHub Pages

1. Upload this folder's contents to your GitHub repository, with `index.html` at the repository root.
2. In Settings → Pages, choose **Deploy from a branch**, then **main** and **/ (root)**.
3. Save and wait for GitHub Pages to finish deploying. GitHub displays the live URL in Pages settings.

For a profile site, name the repository `<your-username>.github.io`. It also works in a project repository, using relative asset paths.

## Updating

Edit `index.html` to update resume details, `styles.css` to change the design, and `script.js` for navigation highlighting. Career statistics and dates reflect the supplied resume. The original resume is not included in the public package. The contact section includes the phone number authorized for publication.

Open `index.html` in a browser for a local preview. All core content and links work without JavaScript.
